HEARTHVALE M2 — PC PLAYTEST

Unzip the whole folder, then double-click Hearthvale.exe. Keep Hearthvale.pck
beside the executable. Windows may show a SmartScreen warning because this
playtest is not code-signed; choose More info, then Run anyway.

MOUSE
  Left-click / hold   Select, confirm, place, or sculpt
  Right-drag         Orbit the camera
  Mouse wheel        Zoom
  Middle-click       Reframe the selected home

KEYBOARD
  W A S D            Move or adjust the current selection
  Tab                Switch between Terrain and Building modes
  X                  Open tools / options
  Enter              Confirm (same as left-click)
  Esc                 Cancel, go back, or pause
  F                   Toggle precision mode
  Q / E               Lower / raise; contextual height controls
  [ / ]               Rotate or cycle left / right
  Z / C               Undo / redo
  Arrow keys          Orbit camera or navigate menus
  - / +               Zoom out / in
  G                   Reframe the selected home
  P                   Pause menu

An Xbox-compatible controller still works. On-screen prompts automatically
switch to match the most recently used input device.
