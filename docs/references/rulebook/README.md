# Visual rulebook image collection

Open [the illustrated board](index.html). Source URLs, SHA-256 hashes, inspection status and annotations are in [image-manifest.json](image-manifest.json).

## Start with these six

Use Town to City 01/02/03 and Station to Station 00/04/07 for architecture, planting and miniature composition. Supporting views deliberately cover other conditions; do not average every palette into one style.

## Shared scale rule

Hearthvale uses a `0.125` world-space visible structural unit across terrain, cottage shells, general vegetation and props. The player-approved cottage-only decorative tier is `0.0625` for window joinery, shutters, trims, roof edges, flower boxes and flowers; structural dimensions, edits and anchors stay at `0.125`. Larger objects contain more cubic cells and must not use enlarged or stretched voxels. Rendering and editing resolution remain separate. These screenshots do not establish an exact numeric unit or prove the source games use either tier.

## Worker briefing use

Assign two or three image IDs per asset. Require the worker to open those actual files, identify the specified regions, and compare the asset beside the current cottage at gameplay zoom. Render and revise; do not substitute a textual reference name for visual inspection. Mandatory Luna delegation remains superseded; this board does not change model policy.
